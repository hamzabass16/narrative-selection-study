Task: retrieve the public-domain English texts listed in /root/analysis/cci/corpus_spec.md (section 2 table) and save each as plain text. Do not score, count or analyse any text, and do not open anything else under /root/analysis.

How to reach the texts. The shell (Bash) cannot reach gutenberg.org or sacred-texts.com; it can reach github.com with git clone. The Chrome browser can reach any site:
1. Load the browser tools with ToolSearch, query "select:mcp__claude-in-chrome__tabs_context_mcp,mcp__claude-in-chrome__tabs_create_mcp,mcp__claude-in-chrome__navigate,mcp__claude-in-chrome__get_page_text,mcp__claude-in-chrome__javascript_tool,mcp__claude-in-chrome__tabs_close_mcp". Call tabs_context_mcp, then create your OWN new tab with tabs_create_mcp and use only that tab. Never touch other tabs. Close your tab at the end.
2. Find each text on Project Gutenberg (https://www.gutenberg.org/ebooks/search/?query=...) and open its plain-text file (https://www.gutenberg.org/cache/epub/<ID>/pg<ID>.txt). If Gutenberg lacks the translation, use https://sacred-texts.com (each book is split into pages; follow the index page links) or another stable scholarly host.
3. To copy a long page into the workspace: call get_page_text on your tab with max_chars set to 20000000. The tool result will say "Output too large ... Full output saved to: <path>". That saved file is a JSON list whose first element has a "text" field holding the page text. Read it with Python in Bash and write the text out. If the tool result is not saved to a file (short page), write the returned text yourself only if it is under 5,000 characters; otherwise retry with the saved-file method.
4. Save each text as /root/analysis/cci/texts/<Tradition>__<ShortTitle>.txt (UTF-8). Strip the Project Gutenberg header and licence (keep only what lies between the "*** START OF" and "*** END OF" lines). Do not otherwise edit the text; prefaces and notes are removed later by a fixed rule.
5. Write /root/analysis/cci/texts/manifest.csv with columns: tradition, file, title, translator, year, source_url, gutenberg_id, n_chars, notes. Record exactly which translation you obtained. If the specified translation is unavailable, use the stated alternative; if no alternative is stated or available, leave that text out and say so in notes. Never substitute a different translation without recording it.

Final reply: one line per text with tradition, title, translator, chars, and any problem.
